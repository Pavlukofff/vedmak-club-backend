# vedmak-club-backend

Бэкенд сайта фехтовального клуба «Своё Дело» (вселенная «Ведьмак»): профили участников, школы фехтования, ранги цеха, бои, бестиарий, квесты, магазин и Лавка алхимика, турниры (включая double-elimination сетку), блог и фестивали, взыскания, сборы средств, титулы и FAQ — плюс админ-панель для управления всем этим.

Полное описание сущностей и решений — в [docs/plan.md](docs/plan.md).

## Стек

- **Django 6 + Django REST Framework** — API
- **django-unfold** — тема поверх штатного Django admin
- **PostgreSQL** в проде, **SQLite** по умолчанию для локальной разработки
- **JWT** (`djangorestframework-simplejwt`) — аутентификация SPA-фронтенда
- **Pillow** — обработка изображений (аватары, фото фестивалей/турниров, товары)

Фронтенд (React) и хранилище медиа — в отдельных репозиториях/сервисах, сюда не входят.

## Быстрый старт

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS

pip install -r requirements.txt

copy .env.example .env       # Windows
# cp .env.example .env       # Linux/macOS

python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Админ-панель: http://127.0.0.1:8000/admin/
API: http://127.0.0.1:8000/api/

По умолчанию используется SQLite — Postgres поднимается только заданием `DATABASE_ENGINE=postgres` и `DB_*` переменных в `.env` (см. `.env.example`).

### Автосгорание взысканий

Замечания/предупреждения сгорают по `expires_at` через management-команду, которую нужно поставить на расписание (cron / Windows Task Scheduler):

```bash
python manage.py expire_penalties
```

## API

Все эндпоинты — под `/api/<приложение>/`, например `/api/accounts/`, `/api/battles/`, `/api/tournaments/`. Аутентификация — JWT:

```
POST /api/auth/token/          # логин, {username, password}
POST /api/auth/token/refresh/  # обновление access-токена
```

Публичные разделы (каталоги, витрины, лента блога и т.д.) читаются без токена; создание/изменение защищено правами Django (`Group`/`Permission`), которые назначаются ролям через админ-панель.

## Админ-панель

Роли клуба (Мастер школы, ДГК, Глава Клуба и т.д.) настраиваются через **Django Groups** — создаёте группу, отмечаете нужные права (включая кастомные вроде `can_issue_penalties`, `can_manage_tournaments`, `can_grant_titles`) и назначаете пользователям. Технический админ сайта — суперпользователь, у него все права по умолчанию.

Стартовая страница админки — дашборд с лентой последних действий (кто и что сделал) и ближайшими днями рождения участников.
